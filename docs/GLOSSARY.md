# Глоссарий Runetime

Интерфейс игры русский, код английский. Эта таблица — единственное
соответствие между ними. Новый термин сначала сюда, потом в код и в строки.

## Сущности мира

| Русский (интерфейс) | Идентификатор (код) | Что это технически |
|---|---|---|
| Гримуар | `grimoire` | хранилище заклинаний игрока |
| Заклинание | `spell` | единица кода: исходник плюс скомпилированный байткод |
| Вязь | `source` | текст заклинания, написанный игроком |
| Кластер | `routine` | заклинание, вызываемое из другого (вне v0.1) |
| Каст | `cast` | один запуск заклинания на арене |
| Эффект | `effect` | воздействие на мир, порождённое `emit` |
| Арена | `arena` | боевая сцена |
| Кастующий | `caster` | сущность, запустившая заклинание |
| Журнал | `trace` | трассировка исполнения каста |

## Виды энергии

| Русский | Идентификатор | Что это технически |
|---|---|---|
| Мана | `fuel` | лимит топлива на один каст |
| Ток | `stack` | стек кадров вызова, LIFO, конечной глубины |
| Прах | `heap` | память заклинания, выделяется и освобождается вручную |
| Скверна | `taint` | невозвращённый прах, мутирует заклинания (вне v0.1) |
| Ларец | `buffer` | буфер фиксированного размера (вне v0.1) |
| Русло | `queue` | очередь, FIFO, порядковые эффекты (вне v0.1) |

## Классы и прогрессия (вне v0.1)

| Русский | Идентификатор | Роль |
|---|---|---|
| Маг | `mage` | базовый класс |
| Антимаг | `antimage` | читает и правит код чужих заклинаний |
| Божество-сборщик | `collector` | высасывает Скверну, ценой паузы |
| Грейд | `rank` | прогрессия от младшего к божеству |

## Правила именования

- Русские строки лежат только в `crates/loc`, ключ вида
  `grimoire.build.success`, `error.R003.title`, `error.R003.detail`.
- Коды ошибок (`C001`, `R003`) генерирует ядро и передаёт в `loc`; текст
  собирается на уровне интерфейса.
- Ключевые слова языка заклинаний не переводятся и не локализуются никогда.
- Если для русского термина ещё нет идентификатора — не придумывай его
  на ходу, добавь строку в эту таблицу тем же коммитом.
